# AI Job Market Analysis Platform

## 项目介绍

基于 Python + Pandas + Streamlit 的 AI 岗位就业市场分析平台。

项目通过对全球 AI 岗位数据进行清洗、分析与可视化，探索 AI 行业的：

- 岗位需求趋势
- 技能要求
- 薪资水平
- 学历要求
- 国家分布
- 远程办公趋势

---

## 技术栈

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Streamlit
- MySQL

---

## 项目功能

- 数据清洗
- 数据分析
- 数据可视化
- 技能词云
- AI岗位趋势分析
- Streamlit数据大屏
